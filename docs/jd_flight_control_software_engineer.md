# 飞控系统软件工程师 — 岗位职责说明书（JD）

## 岗位名称

飞控系统软件工程师（Flight Control System Software Engineer）

## 岗位概述

本岗位隶属于飞控软件集成团队，主要负责将算法团队提供的各类算法模块（如姿态估计、导航定位、轨迹规划等）集成至飞控系统中，并面向最终用户或上层应用完成功能交付。岗位人员无需自主设计或实现底层算法，重点在于系统集成、接口适配、功能验证及产品交付。

---

## 岗位职责

1. **算法模块集成**
   - 理解并使用算法团队提供的算法模块（如姿态解算、位置控制、速度控制、轨迹跟踪等），完成其在飞控系统中的集成与部署。
   - 负责算法模块与飞控主框架（如本项目基于 micro-ROS 的通信与调度框架）之间的接口对接和数据流打通。

2. **系统功能开发**
   - 基于算法模块，完成面向外部的飞控功能开发，包括但不限于：飞行模式切换、自动起降、航点飞行、悬停保持、返航等。
   - 开发和维护飞控系统的状态机、任务管理器及飞行流程逻辑。

3. **通信协议与接口适配**
   - 负责飞控与地面站、遥控器、机载计算机等外部系统之间的通信协议实现（如 MAVLink、uROS topic/service 接口）。
   - 设计和维护飞控对外暴露的 ROS2/uROS 话题、服务和动作接口。

4. **软件调试与问题定位**
   - 在实际飞行测试或仿真测试中，对集成后的系统进行调试，定位并修复软件集成层面的问题。
   - 配合算法工程师分析和复现算法相关问题，提供集成侧的日志与数据支持。

5. **文档与规范**
   - 编写软件集成方案、接口文档及测试报告。
   - 遵守团队编码规范，参与代码评审。

---

## 任职要求

### 必备条件

- 本科及以上学历，计算机、软件工程、电子工程、自动化或相关专业。
- 熟悉 C/C++ 编程，具备良好的工程编码能力和代码质量意识。
- 了解实时操作系统（RTOS）或嵌入式 Linux 的基本开发流程。
- 具备基本的嵌入式系统开发经验，熟悉常见外设通信协议（UART、SPI、I2C、CAN 等）。
- 具备一定的多线程/并发编程基础，理解任务调度与同步机制。

### 加分项

- 有 ROS2 / micro-ROS 使用经验，熟悉 topic、service、action 等通信机制。
- 熟悉 MAVLink 协议及 PX4 / ArduPilot 等开源飞控架构。
- 有无人机/无人系统实际飞行测试经验。
- 了解常见飞行控制回路原理（姿态环、位置环），能读懂控制算法代码。
- 有软件在环（SIL）或硬件在环（HIL）仿真测试经验。
- 熟悉 Git 版本管理，有良好的 CI/CD 实践习惯。

---

## 不要求的技能

- **无需**独立设计或推导飞控算法（如卡尔曼滤波、MPC、PID 调参等底层理论）。
- **无需**具备深度学习或强化学习相关背景。
- **无需**具备飞行力学或空气动力学专业背景。

---

## 工作环境与协作

- 与算法团队紧密协作，作为算法能力的落地实施方，推动算法模块从研究到产品的转化。
- 参与产品需求评审，负责功能可行性评估与软件实现方案制定。
- 日常使用本项目（uros）作为飞控通信与运行框架进行开发工作。
